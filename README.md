# tomfrodyma.com

Personal site of Tom Frodyma. Retro textmode portfolio with playable demos of things I built.

- Built with [Astro](https://astro.build), plain CSS, vanilla JS.
- Visual style inspired by [entropic](https://github.com/CuB3y0nd/entropic) by CuB3y0nd (MIT).
- Font: [Gohufont](https://font.gohu.org/) (WTFPL), taken from entropic's build.

## Develop

```sh
pnpm install
pnpm dev
```
